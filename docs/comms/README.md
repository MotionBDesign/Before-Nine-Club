# MBD Communication System

Pip Decks-based tools and systems for how Motion By Design briefs, gives feedback, manages projects and talks to clients. Built August 2026 from a full audit of Slack (May–Aug) and client email (Jun–Aug).

## Read in this order

1. **`04-findings/findings-report.md`** — what we're doing well, what to fix, and the 7 priority moves. Start here.
2. **`01-pipdecks-foundations.md`** — the Pip Decks tactics behind the system (Hero & Guide, Playback, Rose/Thorn/Bud, Who/What/When, Priority Map, Sailboat).
3. **`02-slack-operating-system.md`** — the day-to-day rules: five message rules, per-client pinned canvas, urgency triage, weekly rhythm.
4. **`03-templates/`** — fill-in templates: `brief.md`, `feedback.md`, `meeting-recap-email.md`, `weekly-status.md`.
5. **`04-findings/`** — the evidence: `slack-audit.md`, `email-audit.md`.

## Claude skills (in `.claude/skills/`)

- **`mbd-brief`** — paste a messy request/thread → complete brief + questions to close it.
- **`mbd-feedback`** — paste scattered comments → one consolidated, anchored feedback round.
- **`mbd-client-email`** — draft/review client emails: recaps, deliveries with change-lists, chases, scope-in-writing.

## The one-sentence version

Keep the tempo and warmth; add **playback** — write down what was briefed, what changed, what shipped, and what was approved, every time.
