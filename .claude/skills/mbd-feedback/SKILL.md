# MBD Feedback Consolidator

Turn loose comments into the round template at `docs/comms/03-templates/feedback.md` so the designer works from one list, not a thread.

## Method

1. **Collect** every comment from the provided sources; dedupe; note who said what.
2. **Anchor** each change to a location (page/frame/timecode). Comments with no location get a `❓ WHERE?` flag.
3. **Translate vagueness**: "make it pop", "feels off", "not quite right" → propose 2-3 concrete interpretations and mark for playback with the commenter. Never pass vague feedback through untranslated.
4. **Sort** into Keep (rose) / Change (thorn, with WHY tied to the brief goal) / Explore (bud, optional).
5. **Flag conflicts**: comments contradicting earlier approved decisions, comments contradicting each other, and comments outside the brief's scope (these need a scope conversation, not silent absorption).
6. **Playback drafts**: for ambiguous client comments, draft the one-line confirmation message ("To play that back: X → Y because Z — correct?").
7. **Output**: the filled round doc + designer-ready summary (numbered actions, due date) + any playback messages to send first.

## Rules
- One consolidated pass per round; state which round this is (e.g. 2 of 2) and warn when rounds are exhausted.
- Preserve praise — designers need to know what to keep, not just what to fix.
- Client's exact words stay quoted next to your translation, so intent is auditable.
